This script:

Loads the Iris dataset using sklearn
Performs data exploration (head, info, missing values check)
Conducts basic statistical analysis (describe, groupby means)
Creates four visualizations:

Line chart of mean measurements across species
Bar chart of average sepal length by species
Histogram of petal length distribution
Scatter plot of sepal length vs petal length


Includes error handling and saves all plots as PNG files
Provides observations about the dataset
